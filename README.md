# Chérie Jewellery E-commerce

Two independent applications are included:

| Folder | Purpose | Stack |
|---|---|---|
| `frontend` | Customer storefront and admin panel | React + Vite |
| `backend` | REST API, images, authentication and invoices | Express + MongoDB Atlas |

## Run locally

1. Install [Node.js LTS](https://nodejs.org/) and create or use a MongoDB Atlas database.
2. Copy `backend/.env.example` to `backend/.env`, then set `MONGODB_URI` and a secure `JWT_SECRET`.
3. In one terminal: `cd backend`, `npm install`, then `npm run dev`.
4. Copy `frontend/.env.example` to `frontend/.env`.
5. In another terminal: `cd frontend`, `npm install`, then `npm run dev`.

The site opens at `http://localhost:5173`. The first backend run creates the admin user from `ADMIN_EMAIL` and `ADMIN_PASSWORD` in `backend/.env`.

The customer’s invoice is generated by the backend as a PDF after checkout. Product images upload to `backend/uploads`. Products, orders, and carousel data persist in MongoDB Atlas.

For the compact project context and endpoint list, see [brain.md](brain.md).
